# Street Garage - site

Site público do jogo Street Garage (https://gusbans.github.io/streetgarage-site/).

- `index.html`: página de apresentação do jogo (hero, recursos, capturas, coleção, cidade, história, teste fechado, FAQ).
- `privacy.html`: política de privacidade.
- `exclusao.html`: exclusão de conta e dados.
- `assets/`: imagens derivadas dos assets do jogo (gerados por `prep_site_assets.py` no repositório principal, pasta `docs/site/`).

As fontes ficam em `docs/site/` no repositório do jogo; este repositório é só a cópia publicada.
